# Kestrel

An autonomous aerial manipulation platform — a quadcopter that
visually locates an object, approaches it, grips it, and relocates it
without human control input.

**Status:** hardware sourcing / pre-integration
**v1 target:** autonomous takeoff → detect → approach → grip → place → land

## Hardware
F450 airframe · H743 FC + 4-in-1 ESC · M10 GPS · servo gripper ·
YOLOv8 perception · ROS2
